# GOODVI — Legal & Support

Static English-language website for GOODVI's legal and support pages. Hosted with GitHub Pages (branch `main`, folder `/(root)`).

Public URLs after enabling Pages:

- Home: https://arifssadykov.github.io/goodvi-legal/
- Privacy: https://arifssadykov.github.io/goodvi-legal/privacy/
- Terms: https://arifssadykov.github.io/goodvi-legal/terms/
- Support: https://arifssadykov.github.io/goodvi-legal/support/

To deploy: upload the **contents** of this folder to the repository root, commit to `main`, then open **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

No build process, external assets, analytics scripts or cookies set by the site.

## Before App Store submission

- Update the pages when subscription availability changes. Verify the data processed by Apple and Adapty in the release configuration and make the App Privacy declarations consistent with the policy.
- Confirm whether standard Apple EULA or separate terms are configured in App Store Connect and maintain consistency with this supplemental Terms of Use page.
- Do not commit app secrets, Adapty API keys, payment credentials, private journal entries or screenshots containing personal data.
